# COVID-19 Data Analysis Dashboard (Power BI)

## Overview
This project presents an interactive Power BI dashboard built using COVID-19 dataset to analyze infection trends, recoveries, and regional spread patterns.

## Features
- Daily and cumulative case trends visualization
- Region-wise comparison of infections and recoveries
- KPI cards for total cases, deaths, and recoveries
- Interactive slicers for date and region filtering

## Tools Used
- Power BI
- Excel / CSV dataset

## Purpose
To demonstrate data cleaning, visualization, and dashboard reporting skills using real-world pandemic data.
